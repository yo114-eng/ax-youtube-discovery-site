적용 범위

이 방침은 개인 운영자가 자신의 탐색 계정에 연결하는 AX YouTube Discovery 데스크톱 도구와 이 소개 사이트에 적용됩니다. 문의: yonggptax@gmail.com.

처리 정보와 목적

  • 계정 이메일과 확인 상태: 승인한 탐색 계정이 맞는지 확인합니다.
  • OAuth 액세스·갱신 토큰과 클라이언트 설정: 승인한 Google API에 인증합니다.
  • 공개 영상·채널 정보, 연결 계정의 구독·재생목록·관심 표시 관련 정보: 자료를 탐색·선별하고 사용자가 위임한 계정 관리를 수행합니다.
  • 요청 시각·처리 결과·변경 이유: 중복 실행 방지, 호출량 관리 및 오류 확인에 사용합니다.

저장과 전송

인증 정보는 Windows 계정에 묶인 암호화 방식으로 로컬에 저장하며, 인증 코드·토큰·클라이언트 보안 비밀을 모델 대화나 일반 실행 로그에 출력하지 않도록 구성합니다. API 인증에는 Google 서버로 필요한 정보를 전송합니다.

자료 선별·추천을 위해 필요한 공개 콘텐츠 메타데이터, 출처 링크 및 계정의 구독·자료 관리 결과 일부는 사용자가 사용하는 OpenAI Codex에 전달될 수 있습니다. 이 처리는 사용자의 OpenAI 계정 설정과 해당 서비스 정책을 따릅니다. 계정의 모든 데이터나 인증 정보를 Codex에 전달하는 방식은 사용하지 않습니다. Google 사용자 데이터를 판매하거나 광고 타기팅, 범용 AI 모델 학습 목적으로 사용하지 않습니다.

보관과 삭제

조회 캐시는 자료 유형별로 24시간 또는 7일 동안 재사용하며, 수집 실행 시 7일보다 오래된 캐시 응답을 정리합니다. 프로그램이 실행되지 않는 동안 자동 삭제가 이루어진다고 보장하지 않습니다. 인증 정보는 연결 해제 또는 로컬 삭제 시까지, 운영 기록과 선택한 자료의 검토 결과는 사용자가 필요한 동안 보관합니다. API 데이터의 보관·갱신은 적용되는 Google/YouTube 정책을 따릅니다.

사용자는 Google 계정의 연결 관리에서 앱 접근을 철회할 수 있습니다. 철회만으로 로컬 파일이 자동 삭제되지는 않으므로, 관련 로컬 인증·캐시·결과 파일도 삭제하거나 운영자에게 삭제를 요청할 수 있습니다. 로컬 데이터를 삭제해도 Google 계정에서 이미 수행한 구독·재생목록 변경은 별도로 되돌려야 합니다.
